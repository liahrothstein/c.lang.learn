# 🎓 C Language Learning: Учебная практика

Репозиторий содержит решения практических задач по программированию на языке **C**, выполненных в рамках учебной ознакомительной практики в **ГГУ им. Ф. Скорины** (специальность «Компьютерная физика»).

## 📋 Обзор учебных задач

Задания охватывают базовые и продвинутые концепции языка С: от циклов до структур и модульного программирования.

| Файл      | Название / Тема                | Ключевые особенности                                                                 |
| :-------- | :----------------------------- | :----------------------------------------------------------------------------------- |
| `task1.c` | **Управляющие конструкции**    | Обработка числовых последовательностей без использования массивов (циклы `while`).   |
| `task2.c` | **Работа с массивами**         | Алгоритм перестановки элементов (сначала нечетные индексы, затем четные).            |
| `task3.c` | **Адресная арифметика**        | Аналог Task 2, реализованный через **указатели** без использования индексов `[]`.    |
| `task4.c` | **Обработка строк**            | Алгоритм вставки символов-разделителей (`=` и `*`) в зависимости от соседних знаков. |
| `task5.c` | **Модульное программирование** | Пример раздельной компиляции с использованием заголовочного файла (`.h`).            |
| `task6.c` | **Структуры и перечисления**   | База данных школ: сортировка структур по нескольким критериям и фильтрация.          |

## 🛠 Технический стек

- **Язык:** C (C99)
- **Компилятор:** GCC
- **Инструменты:** Стандартная библиотека C (`stdio.h`, `stdlib.h`, `string.h`, `stdbool.h`)

## 🚀 Инструкции по запуску

### Одиночные файлы (Задачи 1-4, 6)

Для компиляции и запуска используйте стандартную команду:

```bash
gcc task1.c -o task1
./task1
```

### Модульный проект (Задача 5)

Так как логика вынесена в отдельный файл, компилировать нужно оба `.c` модуля:

```bash
gcc task5.c task5-arr-change.c -o task5
./task5 < task5.in
```
